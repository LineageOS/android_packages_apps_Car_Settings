# Car Settings Debug Utilities

This directory contains scripts to assist with local development and debugging of Car Settings.

## Usage

These scripts are designed to be self-explanatory. You can run them from the root of the Android source tree.

*   `start_settings_fragment.sh`: Launches a specific Settings fragment in dual-pane mode.
*   `increment_install_apk.sh`: Incrementally builds and installs the CarSettings APK.

Refer to the script headers for more details on arguments and requirements.
